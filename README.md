## ⚙️ Development Setup

To run this portfolio site locally, make sure you have [Node.js](https://nodejs.org/) (v18+) and `npm` installed.

### 1. Clone the repository
```sh
git clone https://github.com/KarthikeyatheDev/my-portfolio.git
cd my-portfolio
```

### 2. Install dependencies
```sh
npm install
```

### 3. Run development server
```sh
npm run dev
```
The application will start locally at `http://localhost:5173`.

### 4. Running Tests
To run unit and integration tests (powered by Vitest):
```sh
npm run test
```

### 5. Build for production
```sh
npm run build
```
